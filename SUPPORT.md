# Support And Project Contact

Federation Privacy Library is an experimental open-source library.
There is no technical-support service or service-level agreement. Applications
and operators are responsible for their own deployment, configuration, storage,
keys, monitoring, maintenance, and recovery.

Voluntary community replies and acceptance of a bug report do not create a
commitment to provide support or a fix.

## Non-Technical Project Contact

Contact TechSologic through [support@unolock.com](mailto:support@unolock.com) for
project governance, conduct, and branding enquiries. Include
"Federation Privacy Library" in the subject. This project contact does
not provide library technical support.

Request a private reporting channel before sending sensitive material.
Never send private keys, credentials, live archive content, raw addresses,
authorization proofs, or unedited logs.

## Useful Public Reports

Provide the revision, operating system, runtime and adapter versions when they
exist, minimal reproduction steps, and expected versus observed behavior.
Use synthetic identifiers and minimal sanitized evidence.

Report suspected security-boundary failures privately before publishing a
reproduction. Test only systems you own or are authorized to assess.
