# Maintainers

TechSologic Inc. stewards Federation Privacy Library and controls official
project releases. GitHub organization administrators appoint maintainers and
grant repository access separately. This document grants no platform permission.

Named maintainer and release-role appointments for this repository have not yet
been recorded. Add public identities only with the person's agreement.

## Review Responsibilities

| Area | Review focus |
| --- | --- |
| Public API | Usability, responsibility boundaries, compatibility, completion and error semantics |
| Addressing and discovery | Key commitments, publication, untrusted routing hints, bounded work |
| Messaging | Exact-byte retries, replay protection, custody and receiver completion |
| Archives | Streaming, authorization, integrity, staging, conditional version commits |
| Persistence and recovery | Atomic guarantees, idempotency, concurrency, resumable state, cleanup |
| Transport | Tor integration, cancellation, backpressure, deadlines, resource ownership |
| Dependencies and releases | Licensing, locked inputs, attribution, provenance, reproducibility |
| Documentation | Accurate status, working links, examples, evidence and limitations |

Changes crossing boundaries need review of both sides. Release maintainers must
record the source revision, validation, dependency notices, artifacts, and
remaining limitations before publication.

## Designated Successors

Successor appointments are deferred. No successor maintainer or succession
order has been designated for Federation Privacy Library.

Follow [Governance](GOVERNANCE.md#succession-after-permanent-cessation) for an
authorized handover. Repository access or contribution volume does not itself
make someone a successor.
