# Community Code Of Conduct

This code applies to the project's issues, pull requests, reviews, other project
spaces, and representation of the project elsewhere.

## Expected Conduct

Treat people respectfully regardless of background, identity, experience, or
disability. Discuss technical claims with evidence, accept corrections, give
credit, and respect requests to stop unwanted contact. Criticism should address
the work rather than attack a person.

Harassment, threats, discriminatory abuse, sexual harassment, impersonation,
deliberate disruption, and publishing another person's private information are
not acceptable. These rules apply to maintainers as well as other participants.

## Reporting

For a conduct concern, email [support@unolock.com](mailto:support@unolock.com)
with the subject "Federation Privacy Library conduct report" and request private
follow-up. This is TechSologic's existing project contact mailbox; it does not
provide technical support for the library.

Send only the minimum context needed to route the report. Do not include
credentials, private content, or security exploit details. Vulnerabilities
follow [SECURITY.md](SECURITY.md).

If the concern involves the person handling it, request another repository
administrator. Maintainers should restrict access to people needed to respond
and should not promise absolute confidentiality.

## Response

Maintainers may request corrections, remove harmful content, restrict a
discussion, or temporarily or permanently restrict participation in proportion
to the conduct and its impact. Explain an action when doing so does not expose
private information or cause further harm.

A participant may request reconsideration through the same private route.
A maintainer directly involved in a complaint should not decide its outcome.
